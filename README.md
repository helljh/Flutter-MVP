# 🧠 MVP (Memory Training, Visual Grid, Pattern Game)

> 다양한 게임(숫자, 색상, 경로 등)을 통해 기억력과 집중력을 향상시키는 격자판 패턴 게임 앱

---

## 📱 앱 소개
  
- 숫자, 색상, 경로 등 다양한 패턴 기억력 게임을 제공하며  
- 단계별로 난이도가 올라가는 구조로  
- 재미있게 두뇌를 단련할 수 있는 모바일 앱입니다.

앱스토어에서 실제로 다운로드 가능하며, 기억력 향상을 원하는 누구나 간편하게 사용할 수 있습니다.

## 🛠️ 기술 스택

- **Flutter**
- **Provider** (상태관리)
- **Freezed** (불변 데이터 모델)
- **GoRouter** (페이지 이동)
- **Dart**

---

## 🔑 주요 기능

- **다양한 기억력 게임**:  
  숫자 기억, 색상 기억, 경로 기억 등 3가지 이상 패턴 게임
- **난이도별 플레이**:  
  실력에 따라 난이도 조절, 반복 학습 구조
- **애니메이션 효과**:  
  AnimatedBuilder로 격자판 뒤집기/색상변화 등 UI 효과
- **상태/데이터 관리**:  
  Provider 기반 전역 게임 상태, Freezed 모델 활용
- **조건부 렌더링 안정화**:  
  위젯 Key 관리로 상태 불안정 및 애니메이션 오류 해결
